# Помощник РОПа

Локальный MVP для анализа лидов и сделок Bitrix24 через CLI и UI. Bitrix используется только на чтение.

## Быстрый запуск

Нужны существующие `venv`, `.env` и Node.js.

```powershell
.\venv\Scripts\python.exe -m uvicorn api.app:app --reload --host 127.0.0.1 --port 8000
```

```powershell
cd frontend
npm ci
npm run dev
```

один автоматический цикл анализа всех сделок из выбранных воронок и этапов
```powershell
.\venv\Scripts\python.exe .\scripts\bitrix_crm_cycle_diag.py --one-automatic-cycle
```

API: http://127.0.0.1:8000/api/health
UI: http://127.0.0.1:5173

После старта API в будни с 08:00 до 18:00 МСК каждые 45 минут синхронизирует Bitrix, копит CRM-факты и запускает существующий FULL/MINI/skip. В 15:45 МСК публикуется отчёт «Ежедневный контроль» к планёрке, в 22:00 — дополнительный цикл, в 23:00 — итоговый отчёт за день. Ночью и в выходные не запускается. Отключить: `DAYTIME_CYCLE_ENABLED=false`. Оценка трат OpenAI за московский день: `logs/daily_spend/`.

Правила работы агента: `AGENTS.md`. Архитектура и инварианты: `ARCHITECTURE.md`.

## Если включён локальный VPN/туннель (Happ)

Обычный `npm run dev` может слушать `localhost`, и браузер уйдёт в туннель. Запускай фронт так:

```powershell
cd frontend
npm run dev -- --host 127.0.0.1 --port 5173
```

Открывать только так: http://127.0.0.1:5173

## Локальный запуск агентом для проверки UI

Перед запуском проверь, не работают ли уже API на порту 8000 и frontend на 5173. Используй существующие процессы; не запускай вторые и не останавливай чужие.

Запускай два процесса отдельно. API — из корня проекта, с отключённым автоматическим CRM/AI-циклом:

```powershell
$env:DAYTIME_CYCLE_ENABLED='false'
.\venv\Scripts\python.exe -m uvicorn api.app:app --host 127.0.0.1 --port 8000
```

Frontend — из `frontend/` (если зависимости уже установлены, `npm ci` не нужен):

```powershell
npm.cmd run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Открой http://127.0.0.1:5173 во встроенном браузере Codex. `--strictPort` предотвращает незаметный переход на другой порт. Если frontend показывает `Bad Gateway`, проверь API на http://127.0.0.1:8000/api/health.

Если Vite сообщает о готовности, но браузер получает таймаут, а локальный HTTP-запрос блокируется ошибкой доступа к сокету, проверь ограничения песочницы. В Codex повтори необходимый запуск через `exec_command` с `sandbox_permissions="require_escalated"` и обычной процедурой одобрения. В этой среде запуск вне песочницы позволил открыть сайт по тому же адресу; таймаут сам по себе не доказывает проблему Happ. Не отключай VPN и не меняй сетевые настройки ради проверки.

Проверяй UI на сохранённых данных: не нажимай «Обновить Bitrix» и «Запустить анализ» без соответствующей задачи и разрешения. `DAYTIME_CYCLE_ENABLED=false` отключает только автоматический цикл, а не ручные действия. Запиши идентификаторы запущенных процессов/сессий, чтобы остановить только свои; по окончании проверки останови их, если пользователь не просил оставить сайт включённым.
